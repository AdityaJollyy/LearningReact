# React Learning Projects

This repository contains my React learning projects as I explore and practice React concepts and build my skills.

## About

I'm documenting my journey learning React by building various projects, from simple applications to more complex implementations. Each project focuses on different React concepts and features.

## Projects

- **basic-counter** - A basic counter application to learn state management and event handling

## Getting Started

Each project is self-contained with its own dependencies. To run a project:

1. Navigate to the project folder
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`

## Learning Goals

- Understanding React fundamentals
- Working with components and props
- Managing state and lifecycle
- Building reusable UI components
- Exploring React ecosystem and tools
