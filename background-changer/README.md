# Background Changer

A simple React app built while learning React. Click buttons to change the background color of the page.

## Built With

- React - UI library
- Vite - Build tool
- Tailwind CSS - Styling

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open your browser and visit the local URL shown in the terminal.
